# MASTER PROMPT

## Build an AI-Powered Newsroom + Multi-Platform Social Media Automation Platform

Build a production-ready, scalable **AI Newsroom and Social Media Automation Platform** for a digital news/media organization.

The platform should allow an admin/editor to enter a news topic, URL, press release, uploaded document, RSS source, or manually written information. The AI agent team should research, verify, write, format, generate media, create platform-specific content, send it for approval, and publish/schedule it across:

* Website
* WhatsApp Business
* Facebook
* Instagram
* YouTube
* Optional: Telegram
* Optional: X/Twitter

The system must support both **human-controlled publishing** and **fully automated workflows**.

---

# 1. CORE OBJECTIVE

Create a centralized AI-powered newsroom where:

INPUT
→ Research
→ Source collection
→ Fact checking
→ News writing
→ Headline generation
→ SEO optimization
→ Image generation
→ Social media content generation
→ Video/Short generation
→ Editor approval
→ Scheduling
→ Multi-platform publishing
→ Analytics
→ Performance optimization

Everything should be managed from one admin dashboard.

IMPORTANT:

AI must NOT automatically present unverified claims as facts.

Every generated news story should maintain source references and a clear distinction between:

* Verified facts
* Attributed statements
* Analysis
* Unverified information
* AI-generated material

Provide an editor approval workflow before public publishing by default.

# 2. AI AGENT TEAM

Create a multi-agent architecture.

## AGENT 1 — NEWS RESEARCH AGENT

Responsibilities:

* Search the web for relevant information.
* Collect information from multiple sources.
* Read RSS feeds.
* Process submitted URLs.
* Process uploaded PDFs/documents.
* Identify breaking/trending topics.
* Extract important facts.
* Identify dates, people, locations and organizations.
* Store source URLs.
* Detect duplicate stories.
* Create a research brief.

Output:

```json
{
  "topic": "",
  "summary": "",
  "key_facts": [],
  "sources": [],
  "entities": [],
  "timeline": [],
  "confidence": "",
  "requires_human_verification": true
}
```

# 3. AGENT 2 — FACT CHECKING AGENT

Responsibilities:

* Compare claims against available sources.
* Detect contradictions.
* Identify unsupported claims.
* Flag missing information.
* Detect potentially misleading headlines.
* Identify opinion vs fact.
* Mark information requiring human verification.

Never invent:

* Quotes
* Statistics
* Names
* Dates
* Locations
* Government announcements
* Court decisions
* Election results
* Casualty figures
* Official statements

If information cannot be verified, mark it clearly.

Output a verification report.
